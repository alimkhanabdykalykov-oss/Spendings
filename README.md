# Spendings

Простое приложение для учёта расходов в фунтах (£).

- Категории — это кружки с месячным бюджетом.
- Каждая трата наполняет кружок своей категории, а внутри видно, на сколько процентов он заполнен.
- Если бюджет превышен, кружок становится красным и показывает сумму перерасхода.
- Можно переключаться между месяцами, смотреть и удалять траты (есть «Вернуть»), менять категории.
- Через меню «⋯» можно сделать резервную копию в JSON, загрузить её обратно или выгрузить траты в CSV.

Данные хранятся в браузере (localStorage), сервер не нужен.

## Синхронизация и виджет для iPhone

По желанию данные можно синхронизировать через приватный (secret) GitHub Gist:
так они будут одинаковыми на всех устройствах, а виджет сможет их читать.

1. Создайте токен с правом `gist`: https://github.com/settings/tokens/new?scopes=gist&description=Spendings
2. В приложении откройте «⋯» → вставьте токен → «Подключить».
3. Установите [Scriptable](https://apps.apple.com/app/scriptable/id1405459188), в приложении Spendings нажмите
   «⋯» → «Скопировать скрипт виджета», в Scriptable создайте новый скрипт (＋) и вставьте текст.
4. Добавьте на экран «Домой» виджет Scriptable (маленький, средний или большой), нажмите на него
   в режиме редактирования и выберите ваш скрипт в поле Script.
   Для маленького виджета в поле Parameter можно указать название категории, например `Еда`.

Шаблон виджета лежит в `scriptable-widget.js`.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```sh
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

Чтобы пользоваться с телефона, включите GitHub Pages для этого репозитория
(Settings → Pages → Deploy from branch → `main` / root), откройте ссылку на телефоне
и выберите «Добавить на экран „Домой“». После этого приложение работает и офлайн.
